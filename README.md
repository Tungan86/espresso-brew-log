# Espresso Brew Log (義式咖啡沖煮紀錄 App)

這是一個精美且實用的義式咖啡（Espresso）沖煮紀錄與庫存管理單頁網頁應用程式 (SPA)。

## 🌟 特色功能

- **☕ 庫存管理**：記錄咖啡豆的名稱、烘焙商、烘焙度、烘焙日期、初始重量與剩餘庫存。
- **⏱️ 沖煮助理計時器**：內建精準至百分之一秒的計時器，點擊停止後可一鍵將時間帶入新增紀錄表單中。
- **📝 沖煮數據紀錄**：詳實記錄粉量 (Dose)、液重 (Yield)、研磨度、水溫、壓力、預浸秒數與酸甜苦鹹風味比重。
- **⭐ 星級評分**：提供 1 到 5 星星評分機制。
- **📊 數據可視化**：使用自訂輕量化 SVG 圖表，動態繪製近期萃取時間與評分趨勢。
- **🔄 自動扣庫存**：每次紀錄沖煮時，可自動從該豆子庫存扣除使用粉量。
- **💾 資料隨身帶 (JSON 備份)**：所有資料皆保存在瀏覽器 `localStorage`，並提供備份導出 JSON 與還原導入功能。
- **📱 響應式設計**：針對行動端（直式單手操作）與桌面端（雙欄統計布局）深度優化。

## 📁 檔案結構

```text
/espresso-brew-log/
├── index.html       # 網頁 HTML5 結構與 Modal 彈窗
├── style.css        # 包含玻璃擬態與排版動畫的 CSS
└── app.js           # 業務邏輯、計時器、SVG 圖表與資料儲存
```

## 🚀 快速啟動

由於此 App 為純前端應用，您無須安裝任何伺服器或依賴套件。

1. 直接在瀏覽器中開啟 `index.html` 即可使用。
2. 或是在本專案目錄下啟動一個簡易的本機伺服器：
   ```sh
   # 使用 Python 啟動伺服器
   python3 -m http.server 8000
   ```
   接著在瀏覽器中瀏覽 `http://localhost:8000`。
